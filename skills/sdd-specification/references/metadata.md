# Metadata-first discovery

Search compact metadata to locate plausible specifications, then read every selected specification completely before implementing or reviewing it. Metadata routes; it never replaces the specification body.

Use only applicable fields: `id`, `title`, `summary`, `status`, `scope`, `risk`, `risk_domains`, `reversibility`, `change_surfaces`, `contracts`, `review_policy`, `navigation`, `documentation`, `authority`, and `dependencies`. Prefer stable scalar or short-list values and repository-relative paths. Do not embed secrets, prompts, or evidence logs.
